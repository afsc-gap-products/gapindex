# gapindex: Standard AFSC GAP Product Calculations

This package contains functions to calculate standard NOAA AFSC GAP
summer groundfish bottom trawl survey data products (CPUE, Biomass, Size
Composition, and Age Composition) for the Gulf of Alaska (1990-current),
Aleutian Islands (1991-current), Eastern Bering Sea Shelf
(1982-current), Northern Bering Sea Shelf (2010-current), and Eastern
Bering Sea Slope (2002-2016).
